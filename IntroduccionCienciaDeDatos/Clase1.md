# Data science

Es una ciencia interdisciplinaria que se encarga de extraer conocimiento e información valiosa a partir de datos estructurados y no estructurados. Para ello, se apoya en  métodos científicos, procesos, algoritmos y sistemas  provenientes de diversas disciplinas como:

- Estadística: Para el análisis descriptivo, inferencial y predictivo.
- Ciencias de la computación: Para el desarrollo de algoritmos, el procesamiento de datos a gran escala y la visualización.
- Matemáticas: Para el desarrollo de modelos y la optimización de algoritmos.
- Dominio de aplicación: Conocimiento específico del área donde se aplican los datos (negocios, salud, ciencias sociales, etc.).

El objetivo principal de la Data Science es:

- Descubrir patrones y tendencias ocultas en los datos.
- Obtener información útil para la toma de decisiones.
- Predecir eventos futuros.
- Crear soluciones innovadoras a problemas complejos.

Tecnologías de la información claves en Data Science:

- Big Data: Herramientas para el almacenamiento y procesamiento de grandes volúmenes de datos.
- Machine Learning: Algoritmos que permiten a las máquinas aprender de los datos.
- Data Mining: Técnicas para la extracción de patrones de grandes conjuntos de datos.
- Visualización de datos: Herramientas para representar la información de forma clara y concisa.
