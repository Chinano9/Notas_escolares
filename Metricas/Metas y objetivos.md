# Metas y objetivos

Las metas son declaraciones generales de lo que se espera lograr, mientras que los objetivos son pasos específicos y medibles que se deben alcanzar para cumplir con esas metas.

## Metas
- **Meta 1**: Desarrollar un sistema de información que cumpla con los requisitos del usuario.
- **Meta 2**: Asegurar la calidad y la integridad de los datos
- **Meta 3**: Facilitar el mantenimiento y la escalabilidad del sistema de información.
## Objetivos
- **Objetivo 1**: Diseñar un modelo de datos que refleje las necesidades
- **Objetivo 2**: Implementar un sistema de gestión de bases de datos que permita la manipulación eficiente de los datos.
- **Objetivo 3**: Establecer procedimientos de validación y verificación de
  los datos para garantizar su calidad.
- **Objetivo 4**: Documentar el sistema de información para facilitar su mantenimiento y
  actualización.
- **Objetivo 5**: Capacitar al personal en el uso y mantenimiento del sistema
  de información.
- **Objetivo 6**: Evaluar el rendimiento del sistema de información y realizar ajustes
  según sea necesario.

## Indicadores
Los indicadores son métricas específicas que se utilizan para medir el progreso hacia los objetivos.

## Preguntas para objetivos
Las preguntas deben ser cuantificables y medibles, evitando las preguntas de tipo "sí" o "no".
