# Objetivo

Analizar y determinar la efectividad de las pruebas en un sistema para un banco

# Modelo GQM

| Componente GQM | Descripción |
|----------------|-------------|
| **Objeto de medición** | La efectividad de las pruebas |
| **Propósito** | Analizar y determinar la efectividad |
| **Respecto a** | La efectividad de las pruebas |
| **Punto de vista** | Tester |
| **Contexto** | Sistema para un banco |

# Preguntas

| Pregunta | Metrica |
|------------|---------|
| ¿Cuántas pruebas se han ejecutado? | Número de pruebas ejecutadas |
| ¿Cuántas pruebas han pasado exitosamente? | Número de pruebas exitosas |
| ¿Cuántas pruebas han fallado? | Número de pruebas fallidas |
| ¿Cuántos defectos se han encontrado durante las pruebas? | Número de defectos|
|  ¿Cual es la severidad de los defectos encontrados? | Severidad de los defectos |
| ¿Cuantos modulos han sido probados? | Número de módulos probados |
| ¿Que tipo de pruebas se han realizado? | Tipos de pruebas realizadas |
