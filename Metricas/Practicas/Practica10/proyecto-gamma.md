## Cálculos
1. **Productividad (LDC/Esfuerzo)**:
   Productividad = 20200 LDC / 42 Personas-Mes ≈ 480.95 LDC/Persona-Mes

2. **Costo por LDC ($/LDC)**:
   Costo por LDC = 134000 $ / 20200 LDC ≈ 6.63 $/LDC

3. **Calidad (Errores/MLDC)**:
   Calidad = 256 Errores / 20.2 MLDC ≈ 12.67 Errores/MLDC

4. **Documentación (Páginas/MLDC)**:
   Documentación = 1050 Páginas / 20.2 MLDC ≈ 51.98 Páginas/MLDC

5. **Eficiencia (Defectos/LDC)**:
   Eficiencia = 64 Defectos / 20200 LDC ≈ 0.00316 Defectos/LDC

6. **Tiempo (Esfuerzo/Personas)**:
   Tiempo = 42 Personas-Mes / 6 Personas = 7 Meses
