# Objetivo
Determinar la utilidad y usabilidad de una app movil para el apoyo del aprendizaje de matematicas.

# Modelo GQM
| Componente GQM | Descripción |
|----------------|-------------|
| **Objeto de medición** | Usabilidad y utilidad de una app movil |
| **Propósito** | Mejorar el aprendizaje de matematicas |
| **Respecto a** | El apoyo al aprendizaje de matematicas |
| **Punto de vista** | Estudiante |
| **Contexto** | App movil para el aprendizaje de matematicas |

# Preguntas
| **Pregunta** | **Metrica** |
|------------|---------|
| ¿Cuántas veces se utiliza la app movil por semana? | Frecuencia de uso |
| ¿Cuántas personas usan la app movil? | Número de personas que la usan |
| ¿Cuánto tiempo se usa la app movil en cada sesión? | Duración por sesion|
| ¿Cuánto tiempo se tarda en completar una tarea? | Tiempo para completar una tarea |
| ¿Cuántas tareas se completan en una sesión? | Número de tareas completadas |
