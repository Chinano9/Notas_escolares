# Objetivo

Medir la complejidad de una BD a partir de un modelo de diseño relacional para el desarrollo de un sistema de información, con el fin de asegurar el facil mantenimiento de dicha BD.

# Modelo GQM

| Componente GQM | Descripción |
|----------------|-------------|
| **Objeto de medición** | Complejidad de un modelo de una base de datos |
| **Propósito** | Asegurar el fácil mantenimiento de la base de datos |
| **Respecto a** | La complejidad del modelo de diseño relacional |
| **Punto de vista** | DB Analyst |
| **Contexto** | El desarrollo de un sistema de información |

# Preguntas

| Pregunta | Metrica |
|------------|---------|
| ¿Cuántas tablas tiene el modelo de la base de datos? | Número de tablas |
| ¿Cuántas relaciones existen entre las tablas? | Número de relaciones |
| ¿Cuántas columnas tiene cada tabla? | Número de columnas por tabla |
| ¿Cuántas claves primarias y foráneas existen? | Número de claves primarias y foráneas |
| ¿Cual es la profundidad máxima de las relaciones entre tablas? | Profundidad máxima de relaciones |
| ¿Cuántas columnas tiene toda la base de datos? | Número total de columnas |
