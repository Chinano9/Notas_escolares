# Modelo GQM
Mejorar la calidad del proceso de desarrollo de software, asegurando que el producto final cumpla con los estándares de calidad y satisfaga las necesidades del cliente.

# Modelo GQM

| Componente GQM | Descripción |
|----------------|-------------|
| **Objeto de medición** | Proceso de desarrollo de software |
| **Propósito** | Mejorar la calidad del proceso |
| **Respecto a** | El aseguramiento del cumplimiento de la calidad y satisfaccion del cliente |
| **Punto de vista** | Product Owner |
| **Contexto** | El desarrollo de software |

# Metricas

| Pregunta | Metrica |
|------------|---------|
| ¿Cuántos errores fueron detectados antes de la entrega? | Cantidad de errores en testing |
| ¿Cuánto tiempo se tomo realizar las actividades? | Tiempo por actividad |
| ¿Cuantas lineas de codigo tomo en promedio cada una de las "features" que pidio el cliente? | Tiempo promedio de resolución de defectos |
| ¿Cuántas lineas de codigo se produjeron? | Líneas de código producidas |
| ¿Cuántos errores fueron detectados después de la entrega? | Cantidad de defectos |
| ¿Cuántas lineas de codigo cumplen con los estándares de calidad? | Líneas de código que cumplen con estándares |
| ¿Cuál es el nivel de satisfacción del cliente con el producto final? | Nivel de satisfacción del cliente |
| ¿Cuántas peticiones del cliente se pudieron cumplir? | Cantidad de peticiones cumplidas |
| ¿Cuántas peticiones del cliente no se pudieron cumplir? | Cantidad de peticiones no cumplidas |
| ¿Cuál es el porcentaje de entregas a tiempo? | Porcentaje de entregas a tiempo |
| ¿Cuál es el porcentaje de retrabajo necesario después de la entrega? | Porcentaje de retrabajo |
| ¿Cuánto tiempo se tardo en promedio en completar cada peticion del cliente? | Tiempo promedio por petición |
| ¿Cuántas pruebas unitarias se realizaron en promedio por cada "feature"? | Cantidad de pruebas unitarias por feature |
| ¿Cuántas pruebas de integración se realizaron en promedio por cada "feature"? | Cantidad de pruebas de integración por feature |
| ¿Cuántas pruebas de aceptación se realizaron en promedio por cada "feature"? | Cantidad de pruebas de aceptación por feature |
| ¿Cuál es el porcentaje de cobertura de pruebas? | Porcentaje de cobertura de pruebas |
| ¿Cuántas revisiones de código se realizaron en promedio por cada "feature"? | Cantidad de revisiones de código por feature |
