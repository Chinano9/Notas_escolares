# Objetivo

Analizar y determinar el nivel de cumplimiento de las actividades del proyecto.

# Modelo GQM

| Componente GQM | Descripción |
|----------------|-------------|
| **Objeto de medición** | Nivel de cumplimineto de las acividades |
| **Propósito** | Analizar y determinar el nivel de cumplimiento |
| **Respecto a** | El cumplimiento de las actividades |
| **Punto de vista** | Project Manager |
| **Contexto** | Proyecto de desarrollo de software |

# Preguntas

| Pregunta | Metrica |
|------------|---------|
| ¿Cuántas actividades estaban planificadas? | Número de actividades planificadas |
| ¿Cuántas actividades se han completado? | Número de actividades completadas |
| ¿Cuántas actividades están en progreso? | Número de actividades en progreso |
| ¿Cuántas actividades están retrasadas? | Número de actividades retrasadas |
| ¿Cuántas actividades se completaron a tiempo? | Numero de actividades completadas a tiempo |
| ¿Cuantas actividades se completaron con retrasos? | Numero de actividades con retrasos |
| ¿Cuantas actividades de complejidad alta se retrasaron? | Numero de actividades de alta complejidad retrasadas |
| ¿Cuantas actividades de complejidad media se retrasaron? | Numero de actividades de complejidad media retrasadas |
| ¿Cuantas actividades de complejidad baja se retrasaron? | Numero de actividades de baja complejidad retrasadas |
| ¿Cuál es el porcentaje de actividades completadas respecto al total planificado? | Porcentaje de actividades completadas |
| ¿Cuál es el porcentaje de actividades retrasadas respecto al total planificado? | Porcentaje de actividades retrasadas |
| ¿Cuál es la moda de la complejidad de las actividades retrasadas? | Moda de la complejidad de actividades retrasadas |
| ¿Cuál es la mediana de la complejidad de las actividades retrasadas? | Mediana de la complejidad de actividades retrasadas |
