# Programación  

## Conceptos principales  

### Encapsulación  
Es el principio que permite ocultar los detalles internos de una clase y exponer solo lo necesario para interactuar con ella. Se logra mediante modificadores de acceso como `private`, `protected` y `public`. Esto protege los datos y asegura que solo se acceda a ellos de manera controlada.  

### Herencia  
Es un mecanismo que permite a una clase (clase hija) heredar propiedades y métodos de otra clase (clase padre). Facilita la reutilización de código y la creación de jerarquías entre clases.  

### Polimorfismo  
Permite que diferentes objetos respondan de manera distinta a un mismo método o mensaje. Existen dos tipos principales de polimorfismo:  
1. **En tiempo de compilación** (sobrecarga de métodos).  
2. **En tiempo de ejecución** (sobrescritura de métodos).  

### Abstracción  
Es el proceso de identificar los aspectos más relevantes de un objeto mientras se ignoran los detalles menos importantes. Se implementa a través de **clases abstractas** o **interfaces**, permitiendo trabajar con conceptos generales en lugar de implementaciones específicas.  

### Clases  
Son la estructura principal en la programación orientada a objetos (POO). Representan un modelo o plantilla para crear objetos que comparten características similares.  

#### Atributos  
Son las propiedades o variables que definen el estado de un objeto. Se pueden declarar con diferentes niveles de acceso (`public`, `private`, etc.) y suelen representarse como sustantivos (por ejemplo, `nombre`, `edad`).  

#### Métodos  
Son las funciones o acciones que una clase puede realizar. Representan el comportamiento de los objetos y suelen declararse con un verbo (por ejemplo, `calcular()`, `imprimir()`).
